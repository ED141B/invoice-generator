# Invoice Generator

Application web pour créer et gérer des factures professionnelles.

## Tech Stack
- Vite + React + TypeScript
- Tailwind CSS v4
- Shadcn/UI (composants UI — à utiliser EN PRIORITÉ)
- Lucide React (icônes)

## Commands
- `npm run dev` - Lance le serveur de développement
- `npm run build` - Build pour la production
- `npm run lint` - Vérifie le code

## Rules
- **TOUJOURS** utiliser les composants Shadcn/UI (Button, Card, Input, etc.) — JAMAIS créer des composants UI manuellement si Shadcn en a un
- Pour ajouter un composant Shadcn : `npx shadcn@latest add [nom-du-composant]`
- Les composants Shadcn sont dans `src/components/ui/`
